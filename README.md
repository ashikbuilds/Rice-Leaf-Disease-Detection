# Rice Leaf Disease Detection

## RiceFusionNet: A Dual Branch CNN with CBAM Gated Feature Fusion for Rice Leaf Disease Classification

This repository contains the research implementation, experimental notebooks, evaluation results, cross generalization experiments, and deployment pipeline for automated rice leaf disease detection using deep learning.

The project focuses on developing a robust dual branch convolutional neural network that combines complementary feature representations from **ConvNeXtV2 Tiny** and **EfficientNetV2**.

The proposed architecture, named **RiceFusionNet**, incorporates **CBAM attention** and a **Gated Feature Fusion** mechanism to adaptively combine complementary representations learned from the two CNN branches.

The complete experimental framework includes five fold cross validation, baseline comparisons, ablation studies, cross generalization experiments, and deployment oriented inference.

---

## Project Overview

Rice diseases can significantly reduce crop productivity and affect agricultural sustainability. Early identification of disease symptoms from rice leaf images can support timely intervention and improve disease management.

This project investigates an automated image based rice leaf disease classification framework using modern convolutional neural networks and attention based feature fusion.

The proposed **RiceFusionNet** architecture uses two complementary CNN backbones:

* ConvNeXtV2 Tiny
* EfficientNetV2

The extracted features are refined using **CBAM** and combined using a learnable **Gated Feature Fusion** mechanism.

The main objective is to determine whether complementary representations from two different CNN architectures can improve classification performance and generalization compared with individual backbone models.



# Proposed Architecture

## RiceFusionNet

**RiceFusionNet** is a dual branch CNN architecture designed for robust rice leaf disease classification.

The architecture consists of two parallel feature extraction branches.


                         Input Rice Leaf Image
                                  |
                    +-------------+-------------+
                    |                           |
                    v                           v
             ConvNeXtV2 Tiny              EfficientNetV2
                 Branch                      Branch
                    |                           |
                    v                           v
             Feature Extraction          Feature Extraction
                    |                           |
                    v                           v
                  CBAM                        CBAM
                    |                           |
                    +-------------+-------------+
                                  |
                                  v
                       Gated Feature Fusion
                                  |
                                  v
                         Fused Representation
                                  |
                                  v
                         Classification Head
                                  |
                                  v
                        Disease Prediction


The two branches are intentionally designed to learn complementary representations.

ConvNeXtV2 Tiny provides a modern convolutional representation with strong hierarchical feature learning, while EfficientNetV2 provides an efficient architecture with a different feature extraction behavior.

Instead of simply concatenating the two feature vectors, RiceFusionNet uses attention based refinement followed by gated feature fusion.


# CBAM Attention

The **Convolutional Block Attention Module**, commonly known as CBAM, is used to enhance the discriminative quality of the extracted features.

CBAM applies two types of attention:


Input Feature
      |
      v
Channel Attention
      |
      v
Spatial Attention
      |
      v
Refined Feature


### Channel Attention

Channel attention helps the model identify which feature channels contain the most informative disease related information.

### Spatial Attention

Spatial attention helps the model focus on important spatial regions of the rice leaf, such as visible lesions, discoloration, spots, texture changes, and other disease related patterns.

The combination of channel and spatial attention allows the network to emphasize informative representations while reducing irrelevant information.



# Gated Feature Fusion

A major component of RiceFusionNet is the **Gated Feature Fusion** mechanism.

The feature representations generated by the two branches are first refined using CBAM and then passed to a learnable fusion module.


                 ConvNeXtV2 Features
                         |
                        CBAM
                         |
                         v
                   Feature A
                         |
                         |
                         v
                      Fusion
                         ^
                         |
                         |
                   Feature B
                         ^
                        CBAM
                         ^
                         |
                 EfficientNetV2 Features


The gating mechanism learns the relative contribution of the two feature representations.

Conceptually, the fused representation can be expressed as:


F_fused = G ⊙ F_convnext + (1 - G) ⊙ F_efficientnet


where:


F_convnext       = ConvNeXtV2 feature representation

F_efficientnet   = EfficientNetV2 feature representation

G                = Learnable fusion gate

⊙                = Element wise multiplication


This allows the network to adaptively determine which branch should contribute more strongly to different samples and feature dimensions.

# Five Fold Cross Validation

To obtain a more reliable estimate of model performance, the project uses **five fold cross validation**.

The dataset is divided into five stratified folds.


                 Complete Dataset
                        |
                        v
                Stratified 5 Fold
                        |
       +----------------+----------------+
       |                |                |
       v                v                v
     Fold 1           Fold 2           Fold 3
       |                |                |
       +----------------+----------------+
                        |
                    Fold 4
                        |
                    Fold 5
                        |
                        v
              Aggregate Performance


For each fold:


Training Data = 4 folds

Validation Data = 1 fold


Each fold is used once as the validation set.

The final performance is reported across all five folds where appropriate using mean and standard deviation.

This approach reduces dependence on a single random train validation split and provides a more reliable estimate of model performance.

# Example Model Definition

A simplified representation of the proposed architecture is shown below.


import torch
import torch.nn as nn


class RiceFusionNet(nn.Module):

    def __init__(self, branch1, branch2, feature_dim, num_classes):
        super().__init__()

        self.branch1 = branch1
        self.branch2 = branch2

        self.gate = nn.Sequential(
            nn.Linear(feature_dim * 2, feature_dim),
            nn.ReLU(inplace=True),
            nn.Linear(feature_dim, feature_dim),
            nn.Sigmoid()
        )

        self.classifier = nn.Sequential(
            nn.Linear(feature_dim, 512),
            nn.ReLU(inplace=True),
            nn.Dropout(0.3),
            nn.Linear(512, num_classes)
        )

    def forward(self, x):

        f1 = self.branch1(x)
        f2 = self.branch2(x)

        combined = torch.cat([f1, f2], dim=1)

        gate = self.gate(combined)

        fused = gate * f1 + (1 - gate) * f2

        output = self.classifier(fused)

        return output


The actual implementation used in the experiments may contain additional projection layers, CBAM modules, normalization, dropout, feature alignment, and other architectural components.
